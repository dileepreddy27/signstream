# Data and model card

## Intended use
An inspectable engineering demonstration of temporal landmark classification.
Supported vocabulary: **wave, sweep, raise, circle**. Supported natural sign
languages: **none validated**. These English labels describe procedural motion
curves, not annotated ASL, BSL, ISL, or other linguistic signs. Do not use for
interpretation, accessibility accommodations, or consequential communication.

## Dataset provenance and split
All tracks are generated by `signstream/data.py`; no people, recordings,
external datasets, or personal data are included. Source code, original synthetic
tracks, and trained weights are MIT licensed. Each clip contains 543 xyz slots
in MediaPipe Holistic ordering. Only shoulders and a synthetic right hand are
populated; all face and left-hand slots are zero. Synthetic finger positions
are drawing aids, not anatomically validated signing configurations.

Training: 100 clips/class, validation: 25/class, test: 50/class. Base seeds
1000, 2000, and 3000 are disjoint; each class adds 10000. Independent noise,
camera translation, body scale, and time warping are sampled for each clip.
Evaluation tests generalization to new random draws from the same procedural
generator, **not unseen signers, real cameras, or natural language**.
There is no signer split because there are no human signers.

## Features and training
The full 543-slot payload is validated but the classifier uses only left/right
wrist xyz relative to shoulder center and width, plus two presence flags.
Linear resampling gives 32 × 8 features. Face expressions and finger articulation
are not model inputs. Keras/TensorFlow CPU trains a 24-unit LSTM and 16-unit
dense layer with a four-way softmax. Fixed 18 epochs, Adam 0.008, seed 42.
Validation is logged; the held-out test is evaluated after fitting.
The comparator uses nearest class centroids of time-averaged training features.

See `models/evaluation.json` for the actual run, confusion matrix (true rows),
parameter count, and local CPU timing. Timings exclude landmark extraction,
network latency, preprocessing, and cold start. Hardware/thread scheduling can
change results; exact retraining equality across platforms is not promised.

## Rejection and known failures
Reject malformed shapes, nonfinite/out-of-range coordinates, missing shoulders,
or right-hand presence below 80%. Scores below 0.8 yield no label. Softmax scores
are not calibrated uncertainty or an out-of-distribution detector. Arbitrary
real motions can produce confident wrong labels. No motion segmentation, neutral
class, grammar, sentence translation, or continuous-sign evaluation is provided.
Camera windows are non-overlapping 32-frame buffers; variable capture rates can
change recognition. Left-handed motion is not supported by this synthetic model.

## Third-party dependencies
Keras and TensorFlow: Apache-2.0. MediaPipe: Apache-2.0 (browser assets loaded on
request from a pinned jsDelivr package; not copied into this repository).
NumPy: BSD-3-Clause. FastAPI, Uvicorn, pytest, HTTPX, Ruff: MIT.
Google Fonts are optional presentation assets (DM Sans and Space Grotesk, OFL);
system sans-serif fallback works offline. Dependencies retain their own licenses.
No third-party images or human video are distributed.
